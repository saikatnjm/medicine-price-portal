# Architecture

See also [DECISIONS.md](DECISIONS.md).

## Phase 1

Next.js 16 (App Router, Server Components) · TypeScript (strict) · Tailwind CSS v4 · local seed data · Docker Compose · Vercel

```
src/app (routes, Server Components)
  ↓ imports `services` from "@/data"
src/services        MedicineService, SearchService, PharmacyService (+ summaries helpers)
  ↓ depends on interfaces
src/repositories    MedicineRepository, GenericRepository, ManufacturerRepository,
                    PharmacyRepository, PriceRepository
  ↓ implemented by
src/data/local      createLocalRepositories(dataset) + in-memory search
  ↓
src/data/local/seed/*.json   (generated by scripts/generate-seed-data.mjs)
```

`src/data/index.ts` is the composition root (marked `server-only`): it builds repositories and services and is the only file that changes when the data source changes.

```
  lib/          formatting, routes, SEO helpers, search config/params, site config

scripts/        seed data generator
```

## Rendering

- Medicine and pharmacy pages are statically generated (`generateStaticParams`); unknown slugs call `notFound()` (HTTP 404). `dynamicParams` stays on, so an API provider can serve medicines added after the build.
- `/search` renders on the server from `searchParams`; it has a `loading.tsx` skeleton.
- The only Client Component is `app/error.tsx` (required by Next.js). Search works without client JavaScript.

## Future

```
src/app → src/services → src/repositories → src/data/api (ApiRepositories + DTO mappers)
                                              → Django REST API → PostgreSQL
```

The API provider maps DRF responses (snake_case, decimal strings) to domain types. Services and UI stay unchanged.

## Rules

- UI must never import `@/data/local`, seed JSON, repositories or service modules directly (ESLint-enforced). It uses `services` from `@/data`.
- Domain types stay independent of storage.
- Repository methods are async.
- No database, search engine, Redis or Django in Phase 1.

## Future Infrastructure

Potential future architecture: Next.js, Django REST Framework, PostgreSQL, Redis, Meilisearch, Celery, object storage, pharmacy integrations. Documented for planning only.
