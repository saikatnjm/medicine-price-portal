# Medicine Price Portal

## Vision

Build a trustworthy medicine information and price comparison platform.

The platform should help users discover medicine information, compare prices between pharmacies, understand generic/brand relationships, and eventually find medicine availability.

## Initial Goal

Validate the product concept with a completely free public pilot.

The pilot will use sample/local data and will not depend on paid APIs or external databases.

## Phase 1 User Journey

User visits homepage.

User searches for:

"Napa"

The system shows matching medicines.

User selects:

"Napa 500mg"

The system shows:

- brand name
- generic name
- strength
- dosage form
- manufacturer
- pack information
- sample pharmacy prices
- same-generic alternatives

User can navigate to pharmacy pages.

## Product Principles

1. Search must be extremely easy.
2. Information must be easy to scan.
3. Price comparison must be obvious.
4. The interface must feel trustworthy.
5. Mobile usability is critical.
6. SEO is a major acquisition channel.
7. Demo data must never be presented as live data.
8. The architecture must support future backend integration.

## Target Market

Initial target:

Bangladesh.

The system should be designed so localization can be added later.

## Business Model

Not implemented in Phase 1.

Potential future models:

- pharmacy subscriptions
- sponsored listings
- pharmacy integrations
- medicine ordering commissions
- API access
- healthcare partnerships
