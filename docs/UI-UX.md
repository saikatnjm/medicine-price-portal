# UI/UX Guidelines

## Design Goal

Professional healthcare information portal.

The interface should communicate:

- trust
- simplicity
- accuracy
- usefulness

## Primary Actions

1. Search for a medicine
2. Search for a healthcare provider (hospital, clinic, doctor, pharmacy)
3. Browse by specialty or location

The search box should be visually prominent; it should accept both medicines and provider names/specialties/locations.

## Visual Style

Use a restrained professional design.

Avoid:

- excessive gradients
- excessive shadows
- excessive rounded cards
- flashy animations
- AI-generated-looking visual patterns

## Information Hierarchy

Medicine name
↓
Generic
↓
Strength/form
↓
Price comparison
↓
Pharmacy
↓
Alternatives
↓
Additional information

## Mobile

Mobile-first.

Medicine price comparison must remain easy to scan on narrow screens.

Avoid wide tables that require excessive horizontal scrolling.

## States

Every major interactive area needs:

- loading state
- empty state
- error state
- success/normal state
